## Documentation Index
<a href="#documentation-index"></a>

This project is based on [OpenACR](/txt/openacr/README.md), a
generative meta-programming framework: ssimfiles (ascii relational
tables) are the source of truth and `amc` generates the bulk of the
C++ from them.

For OpenACR fundamentals — installation, ssim format, the standard
toolchain, common recipes, and the C++ style guide — see
[/txt/openacr/README.md](/txt/openacr/README.md).
