```
struct FDb { // wt.FDb: In-memory database for sandbox
```

```
struct FSandbox { // wt.FSandbox
    wt::FSandbox*      ind_sandbox_next;      // hash next
    u32                ind_sandbox_hashval;   // hash value
    algo::Smallstr50   sandbox;               //
    bool               cow;                   //   false  Materialize as cow farm when the host has cowdancer; worktree otherwise
    algo::cstring      comment;               //
    algo::cstring      dir;                   //
    bool               select;                //   false
    // func:wt.FSandbox..AssignOp
    inline wt::FSandbox& operator =(const wt::FSandbox &rhs) = delete;

    inline               FSandbox(const wt::FSandbox &rhs) = delete;
private:
    // func:wt.FSandbox..Ctor
    inline               FSandbox() __attribute__((nothrow));
    // func:wt.FSandbox..Dtor
```


### Tests
<a href="#tests"></a>
The following component tests are defined for `wt`.
These can be executed with `atf_comp <comptest> -v`
|Comptest|Comment|
|---|---|
|[wt.Anon](/test/atf_comp/wt.Anon)|Anonymous cow sandbox in a scratch checkout: create, run, delete|
|[wt.Clean](/test/atf_comp/wt.Clean)|Clean removes cow sandbox contents (scratch checkout)|
|[wt.Command](/test/atf_comp/wt.Command)|Multi-argument command in cow sandbox (scratch checkout)|
|[wt.Create](/test/atf_comp/wt.Create)|Registry roundtrip in a scratch checkout|
|[wt.Del](/test/atf_comp/wt.Del)|Delete a sandbox that was never materialized (scratch checkout)|
|[wt.Diff](/test/atf_comp/wt.Diff)|Diff is not supported for a cow sandbox (scratch checkout)|
|[wt.List](/test/atf_comp/wt.List)|List with stdin sandbox data|
|[wt.Reset](/test/atf_comp/wt.Reset)|Explicit reset of cow sandbox, then run (scratch checkout)|
|[wt.StdinMulti](/test/atf_comp/wt.StdinMulti)|Multi-line stdin script runs in cow sandbox (scratch checkout)|
