### Tests
<a href="#tests"></a>
The following component tests are defined for `gcache`.
These can be executed with `atf_comp <comptest> -v`
|Comptest|Comment|
|---|---|
|[gcache.CacheDirFail](/test/atf_comp/gcache.CacheDirFail)|a cache directory that does not exist must fail the run around a wrapped command that succeeds|
|[gcache.CoverageBlobMiss](/test/atf_comp/gcache.CoverageBlobMiss)|a cache entry that is not a whole coverage blob counts as a miss and is republished|
|[gcache.CoverageFlag](/test/atf_comp/gcache.CoverageFlag)|which compiler flags select the coverage cache format|
|[gcache.CoverageRestoreFail](/test/atf_comp/gcache.CoverageRestoreFail)|a coverage cache hit restores both halves of the blob or leaves neither fresh|
|[gcache.EmptyEntry](/test/atf_comp/gcache.EmptyEntry)|an entry a compile cannot be served from -- no bytes, or a directory -- is a miss in both formats|
|[gcache.ExitCodeCount](/test/atf_comp/gcache.ExitCodeCount)|the exit code sums the wrapped command status and one per failure that costs the object|
|[gcache.HitMtime](/test/atf_comp/gcache.HitMtime)|a cache hit leaves every file it writes carrying the time of that hit|
